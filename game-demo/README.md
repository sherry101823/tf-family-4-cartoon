# 第肆束光 · 明星养成 Demo

浏览器中的中文养成小游戏：单人培养张函瑞，或培养王橹杰、张桂源、左奇函三人团体。每局 24 日，经过三个阶段，完成训练、背景事件、阶段舞台和成长结局。

## 打开

可以直接双击 `index.html`。若浏览器限制本地存档，推荐从仓库根目录启动本地服务：

```powershell
python -m http.server 8714 --bind 127.0.0.1
```

然后打开 <http://127.0.0.1:8714/game-demo/>。按 Ctrl+C 停止服务。必须在仓库根目录启动，图片引用了上一级的素材目录。

## 玩法

1. 选择单人或三人模式。
2. 点击日程卡安排训练、休息或互动；“建议日程”会根据当前状态填入剩余时段，可以随时修改。
3. 逐格执行。压力或疲劳达到 15 时先恢复；休息占时间，但不花星币。
4. 第 8、16、24 日晚选择三段舞台节目；团体分别安排每位成员的主表现。4 秒的应援互动最多 +5 分，可以跳过。
5. 完成背景事件、解锁阶段形象，最后查看结局、前后属性和成长手记。

两种模式分别自动保存到浏览器 localStorage。点击“写下第一天”或“重新开始”会提示是否覆盖当前模式存档。清除浏览器数据会删除存档；file 地址、不同 HTTP 端口与不同浏览器的存档互不相通。

## 素材和设定

全部人物图片引用现有“TF家族四代_三时期卡通形象”资源，未修改原图。像素形象使用整体位移与缩放，静态资源没有被描述成独立动作帧。可关闭动画，并尊重系统的减少动态效果设置。

背景名称与资料年份来自用户提供的时间线；没有另行进行事实核查。角色数值、培养方向、事件选择、团体编制、对话和最终出道属于游戏设定，不能当作现实人物能力评价或官方出道安排。

## 文件

- `engine.js`：数据配置、训练/恢复、日程、事件、评分与结局。
- `app.js`：页面、素材映射、轻量互动和存档。
- `style.css`：桌面/窄屏布局及动画。
- `test-engine.cjs`：预算、状态、收益去重和完整培养流程验证。

不需要安装 npm 依赖。若有 Node.js，可运行 `node --test game-demo/test-engine.cjs`。
